# 视频编辑器交互审查

日期：2026-11-01。范围：PixomaStudio 的视频编辑器、Chat、项目资产和保存导出流程。

本文记录源码核查结果、建议行为和运行验收要求。建议行为尚未实现；源码证据与运行证据分别标明。用户列举的七项问题用于引出完整创作流程的审查。

## 1. 开始创作与继续编辑

### 已核查的代码

- `src/features/studio/video-editor.tsx`：预览空状态只有创建固定茶品牌五个分镜的按钮；工具栏另有新增分镜。
- `src/features/studio/video-editor.tsx`：新增和复制分镜均追加到列表末尾。复制后保留素材和参数，清除 `executionId`。
- `src/features/studio/studio-workspace.tsx`：视频标签使用 `forceMount`；同一会话切换工作台标签时保留编辑器实例。编辑器使用 `sessionId` 作为 React key。
- `src-tauri/src/video_project.rs`：空作品读取结果为「未命名视频」，作品按会话读取和保存。

### 建议行为

- 空作品提供「输入创作想法」「添加分镜」「导入素材」，创建入口接入同一份作品数据。
- 输入想法后选择整片或目标分镜范围，进入 Chat 生成剧本和分镜。
- 新增或复制分镜插入所选分镜之后；没有选择时追加到末尾。新对象进入选择状态，名称可以直接编辑。
- 删除分镜后选择相邻分镜。删除最后一个分镜后显示空作品入口。
- 切换会话前处理待保存内容；重新打开时恢复作品和编辑位置。

### 验收

从空会话分别通过想法、空白分镜和真实视频导入开始创作。核对插入位置、选择状态、保存后的内容和重新打开后的内容。

## 2. 剧本、分镜与 Chat

### 已核查的代码

- `video-timeline.tsx:textEdit`：双击剧本和字幕都打开行内文本框，没有想法输入和 Chat 生成调用。
- `video-editor.tsx:reference`：对话入口创建包含作品内容的文本资产，再调用 `onReference` 加入 Chat 引用。
- `studio-chat.tsx:send`：消息可以携带 `selectedSkillIds`、资产引用和结构化消息片段；运行期间支持排队。
- `src-tauri/src/skills.rs:requested_skills`：支持按 `skill_id` 和版本引用技能。
- `src-tauri/src/tools.rs`：已提供 `studio_read_video_project`、`studio_write_video_project`、`studio_update_video_shot`。
- `video-editor.tsx:chooseWorkflow`：选择工作流时可以从 `shot.script` 初始化 `prompt`；随后修改剧本只修改 `script`。

### 建议行为

- 双击空剧本打开想法输入，提供明确的生成按钮和手动编写入口。已有剧本双击编辑，并提供「用 Chat 改写」。
- 请求携带会话、作品修订、目标分镜 ID、创作想法和确切 Skill 版本；当前选择改变后，请求范围保持原值。
- 剧本 Skill 使用当前会话可用技能。唯一匹配时自动选用；多个匹配时显示选择；缺少技能时提供安装或选择入口，保留想法草稿。
- 请求通过现有 Chat 消息队列提交。编辑器展示等待、生成、写回和失败状态，并能定位对应消息。
- Chat 原有输入草稿保留；重复点击生成不会提交第二份相同请求。
- 写回之前检查目标对象和修订。目标删除时终止写回；同一字段被手动修改时保留两份内容供选择。
- 剧本、画面描述和生成提示词分别表达创作意图。提示词需要更新时提供「根据剧本更新提示词」，保留手动编写的生成参数。
- 整片生成可新增分镜；分镜改写只修改目标分镜中获准修改的内容。

### 验收

使用真实 Skill 和模型生成剧本，核对消息引用、工具调用、数据库内容和时间轴显示。覆盖排队时切换分镜、原有 Chat 草稿、重复提交、生成时手动修改、删除目标、缺少 Skill 和失败后重试。

## 3. 资产从查找到使用

### 已核查的代码

- `video-editor.tsx`：资产卡片包含预览按钮和同一行的对话图标按钮；没有拖放处理。
- 资产筛选仅使用名称搜索，没有类型筛选和选中资产状态。
- `video-timeline.tsx`：参考资产数量通过 `shot.inputs` 内的对象值计数。
- `video-editor-model.ts:VideoShot`：没有独立的参考列表和画面描述字段；工作流输入保存在 `inputs`。
- 参考属性区展示已采用视频的首尾帧及传给下一分镜的操作。
- `video-editor.tsx:upload`：一次只读取文件选择中的第一项。

### 建议行为

- 资产卡片使用缩略图、名称和必要类型信息；更多操作固定在卡片角部，可通过键盘访问。
- 搜索与类型筛选共同作用，区分正在读取、没有资产、没有搜索结果和读取失败。
- 单击选择资产，双击在预览区查看。提供添加到当前分镜、添加到 Chat、查看版本等操作。
- 支持从资产库拖入时间轴，显示目标轨道、分镜和操作名称；无效位置明确显示不可放置。
- 图片拖入分镜用于分镜图，拖入参考轨道登记图片参考；视频拖入视频轨道用于采用素材；音频拖入参考轨道登记参考，拖入成片音频轨道参与混音。
- 视频拖到时间轴末尾创建新分镜；拖到已有视频块替换采用素材，并保留历史版本。
- 参考独立保存资产 ID、版本 ID 和用途。选择工作流时明确关联可接收的输入字段；多个输入字段可用时展示选择，缺少输入时保留参考资料并指出生成所需配置。
- 参考支持查看、替换、移除和调整用途。相同参考重复加入时保持单个引用；不同用途可以分别登记。
- 导入支持多个文件，逐项显示结果；导入到哪个分镜在开始时确定。
- 所有拖放动作提供菜单入口，引用与采用操作都支持撤销。

### 验收

使用真实图片、视频、音频和文档，逐项检查可用位置、具体版本、重复引用、跨分镜拖放、工作流输入以及重新打开后的内容。参考音频保持静音，成片音频能够播放。

## 4. 选择、预览与播放位置

### 已核查的代码

- `video-editor.tsx:select`：选择分镜会退出资产预览并将播放位置设置为分镜起点。
- `displayProject`：循环当前分镜时构建只有该分镜且 `audio: []` 的预览数据。
- `AssetPreview` 与 Remotion `Player` 条件渲染，切换资产预览会替换播放器实例。
- 预览工具栏包含播放、时间显示和退出分镜循环；没有逐帧、音量、全屏和画面缩放控制。
- 资产预览使用原生媒体 controls；文档预览当前只显示名称。

### 建议行为

- 编辑选择、播放位置和预览来源分别保存。单击对象更新选择与属性；时间标尺、播放游标和定位命令改变播放位置。
- 预览来源明确显示整片、当前分镜或资产。循环播放作为独立开关。
- 当前分镜预览保留与该分镜时间范围相交的成片音频，并换算开始时间与素材范围。
- 资产预览显示名称、版本和类型；返回作品预览后恢复原来的播放位置与模式。离开当前预览时暂停它的音频和视频。
- 提供播放暂停、前后逐帧、返回开始、上一分镜、下一分镜、时间输入、静音、音量、适应画面和全屏。
- 时间显示使用帧率对应的帧位置；空分镜保持计划时长并显示分镜名称与素材状态。
- 媒体读取失败在预览区提供重试，保留作品和时间轴。

### 验收

使用带声音的视频和跨分镜音乐，对比整片与当前分镜相同时间点的声音。覆盖预览来源切换、播放中选择对象、关闭预览、逐帧定位、首尾边界和读取失败。画面结构通过 DOM 和尺寸检查验证。

## 5. 时间轴作为连续编辑区域

### 已核查的代码

- `video-editor.css`：轨道行 `border: 0`；块外部 `padding: 3px 2px`；块有独立圆角、底色和边框。
- `video-timeline-model.ts:createTimelineRows`：剧本、分镜、参考、视频和字幕共用分镜边界；视频轨道允许拖动和裁剪。
- `video-timeline.tsx`：已有拖动预览、帧间隔吸附、边界辅助线、自动滚动和冲突检查。
- 所有分镜轨道共用 `selectedId`，音频点击通过无对象参数的 `onAudio()` 打开声音属性。
- 缩放使用固定增减按钮；`gridSnap` 始终开启。

### 建议行为

- 各轨道共享连续表面；轨道之间使用横向分隔线，分镜之间使用纵向分隔线。选中对象与所属分镜范围具有不同的视觉提示。
- 轨道标题固定显示；时间轴内部独立滚动。轨道支持折叠，音频重叠时保持各对象可选。
- 分镜名称行支持调整顺序，资料轨道跟随所属分镜移动。视频边缘裁剪操作与分镜排序操作有明确反馈。
- 提供适应全部、缩放、吸附开关和跳转当前播放位置；缩放保持播放游标附近的位置可见。
- 拖动期间显示目标位置与时间；越界或源素材不足时显示具体限制，取消拖动恢复原始数据。
- 键盘快捷键与指针操作共用相同业务动作。输入框和文本编辑器中的快捷键保留原生行为。
- 音频选择保存具体 `audioId`；删除动作作用于当前对象，分镜删除通过分镜操作入口表达。

### 验收

覆盖不同时长分镜排序、左右裁剪、缩放后拖动、滚动后拖动、音频选择与删除、取消手势、键盘编辑以及各关联轨道边界。已有拖动冲突保护继续通过验收。

## 6. 属性与紧凑布局

### 已核查的代码

- `video-timeline.tsx`：剧本、分镜和字幕点击都进入 `shot` 属性标签。
- `video-editor.tsx`：`shot` 标签同时显示名称、剧本、字幕；声音标签一次列出全部音频表单。
- `video-editor.css`：时间轴固定高度为 280px，属性区固定宽度为 300px；预览和资产区域没有上下调节分隔条。
- 低于 600px 的编辑器容器中，属性区覆盖时间轴；页脚操作采用换行排列。
- `src/components/ui/resizable.tsx` 已有可复用的面板和分隔条组件。

### 建议行为

- 作品工具栏、预览与资产区、时间轴形成紧凑工作区，区域边界清楚；上下区域通过可拖动分隔条调整高度。
- 预览、资产、属性各自滚动和收起；保存面板尺寸并提供恢复布局。收起区域后释放空间。
- 剧本属性只显示剧本；分镜属性显示名称、画面描述、分镜图和计划时长；参考属性显示素材与用途；字幕属性显示字幕内容；视频属性显示采用版本、源范围和音量；音频属性只显示选中音频。
- 生成设置归属所选分镜，常用动作可见，其余动作进入更多菜单。
- 窄窗口通过面板切换保留编辑空间；属性浮层具有关闭入口、焦点管理和 Escape 行为。
- 控件继续复用 shadcn/ui，颜色沿用语义令牌；编辑器内部采用紧凑间距和字号，触屏操作保留足够的点击范围。

### 验收

逐一选择每种对象并核对字段和可用动作。检查亮暗主题、长名称、长剧本、空内容、多音频、窗口缩放、键盘焦点、布局恢复和内容溢出。

## 7. 修改、撤销与保存

### 已核查的代码

- `video-editor.tsx:commit`：每次调用都增加历史记录；属性输入的 `onChange` 直接调用 `patchShot`。
- `video-editor-model.ts:fitVideoProjectTiming`：作品缩短后过滤开始位置超出片尾的音频，并缩短其余越界音频。
- `adoptVideoMedia`：采用素材时源起点归零，分镜时长取计划时长与素材时长中的较小值。
- 自动保存延迟为 700ms；编辑器卸载时清除尚未触发的定时器。
- `restore` 清空撤销和重做历史；外部修改与本地草稿同时存在时，界面提供读取最新项目或保留本地编辑。
- 前端尺寸校验只检查正整数；服务端保存限制尺寸不超过 4096、帧率不超过 60，导出还要求尺寸至少为 16 且为偶数。

### 建议行为

- 一次文字编辑、一次拖动、一次素材替换各形成一条撤销记录；输入未提交期间使用本地草稿。
- 表单提交时校验数值和范围，错误显示在对应字段。项目设置与保存、预览、导出的限制保持一致。
- 缩短分镜或采用较短素材前展示时间变化和受影响音频；确认后以单个操作提交全部变化，撤销恢复全部关联内容。
- 保存状态区分读取中、未保存、保存中、已保存、保存失败和版本冲突。
- 离开会话或关闭窗口时，已修改内容必须保存成功或保留可恢复草稿。保存失败提供重试并保留输入。
- Chat 写回和生成结果更新保留手动编辑；版本冲突显示受影响对象与字段，提供可核对的内容选择。
- 撤销编辑不重新提交生成任务。异步结果按请求关联和对象 ID 处理。

### 验收

覆盖文字输入后撤销、连续拖动后撤销、采用较短视频、音频越界处理、修改后立即切换会话、保存失败后恢复、两个入口修改相同或不同字段、撤销后收到生成结果。

## 8. 生成、采用与导出

### 已核查的代码

- `collectVideoMedia`：首次生成在参数保持一致时自动采用；已有视频或参数变化时保存为候选。
- 当前视频、候选和历史可以保留；属性中的版本卡片提供预览与采用。
- `shotStatus` 将生成状态、候选状态、参数变化和素材状态依次选择一项显示。
- 导出按钮在任意分镜没有视频时禁用；界面没有逐项检查结果和定位动作。
- 导出使用现有 Rust/FFmpeg 流程，服务端核对素材、范围、画幅和音频。导出成功后将成片加入 Chat 引用。

### 建议行为

- 分镜同时表达采用素材、生成任务和资料变更状态；生成过程中继续预览当前采用视频。
- 生成入口显示缺少的工作流、参数、参考或计算节点。失败提供对应任务与重试动作。
- 候选列表显示来源、版本、时间和采用状态，支持预览后采用。采用操作检查素材时长与作品内容。
- 导出入口提供检查结果，逐项定位缺少视频、素材不可读、范围无效、音频无效或保存失败的对象。
- 导出使用提交时的作品快照；后续编辑不改变本次导出内容。
- 导出中显示实际阶段；仅在服务端提供进度时展示百分比。成功后提供播放和保存文件，失败后保留作品并提供重试。

### 验收

使用真实生成任务、媒体和导出文件，核对候选归属、当前视频保留、采用历史和失败恢复。通过 FFprobe 检查导出尺寸、帧率、时长、音轨，并检查连接处的解码结果。

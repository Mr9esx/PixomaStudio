## 原生验收执行条件

- `native_layout.rs` 使用隐藏、不主动聚焦且不显示在任务栏的窗口，macOS 配置 `ActivationPolicy::Prohibited`；共享程序及其十个调用脚本没有显示、恢复或聚焦窗口的操作请求。`cargo check --example native_layout` 和十个脚本的 `node --check` 通过，此项只证明编译及语法。
- 当前 `tauri-plugin-single-instance` 2.5.4 的 macOS 实现固定使用 `/tmp` 下的 socket，未提供目录参数。[上游当前 macOS 源码](https://raw.githubusercontent.com/tauri-apps/plugins-workspace/v2/plugins/single-instance/src/platform_impl/macos.rs) 同样使用固定目录。仓库约定禁止读写该目录，因此没有运行原生验收程序。隐藏运行和系统层面的窗口行为尚未取得运行证据，当前 App 与挂起的自动重启监听保持原状态。
- 已连续核对当前依赖实现、上游实现及当前进程，运行条件没有改变。剩余完整桌面联动、原生媒体协议、窗口与系统保存操作需要实际原生运行证据；现有组件和服务检查无法证明这些要求已经满足。继续原生验收需要先解决依赖固定使用禁止目录的问题，期间不恢复自动重启监听、不启动验收 App。

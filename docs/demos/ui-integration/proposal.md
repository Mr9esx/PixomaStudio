# Studio 页面与编辑交互方案

## 表面与层级

保留当前 Studio 导航、主题、字体、组件形状和主体表面。主体保留一层圆角边框，标题、工具栏和内容之间使用留白；资源集合使用开放式排列，文件目录和属性区域使用次级底色。输入框、代码编辑器和可调整面板保留必要边界。

选中状态通过缩略图轮廓、文字字重和背景表达。标签页使用文字层级表达当前位置。列表通过间距与 hover 背景区分条目。

## 资产库

- 左侧保留项目与分类，中间展示资产；类型筛选、搜索与视图切换放在同一工具栏。
- 选择资产后，在当前页面右侧展开属性区域，可编辑名称、查看来源与版本。
- 大预览进入当前主体区域，使用面包屑和返回按钮回到资产列表。
- 返回时保留类型、项目、视图和选择状态；正式页面还应保留搜索与滚动位置。
- 窄屏将属性区域排列在列表后面，项目树转为横向选择。

## 工作流

- 自建 ComfyUI 与在线模型共用工作流入口，通过类型筛选区分。
- 列表使用封面、名称、介绍和类型排列，资源外围保留留白。
- 详情在主体内提供介绍、配置、版本、执行记录。
- 添加和编辑使用主体页面；自建 ComfyUI 展示导入文件、输入输出绑定和计算节点，在线模型展示服务连接与模型配置。
- 计算节点由工作流配置引用，维护入口位于设置。
- 运行页面在同一主体展示输入与结果，返回时保留当前工作流。

## 技能与专家

- 共用导航入口，页面内切换技能、专家。
- 创建和编辑进入主体页面，顶部使用面包屑、编辑状态、返回与保存操作。
- 技能以文件树和正文编辑器为主要区域，基本信息与版本记录使用标签页切换。
- 专家使用提示词、工作方法、基本信息和版本记录，引用的技能与工作流显示在同页侧栏。
- 保存时在当前页面展开版本号、说明与内容变化，保留正文编辑区域。
- 导入完成后进入相同编辑页面，检查文件后保存。
- 未保存内容离开页面时，使用小型确认框提供继续编辑和放弃修改。
- 窄屏将文件树转为正文上方的文件选择区，侧栏信息排列在正文后面。

## 实施范围

复用现有资产网格、技能文件树、编辑器、工作流表单与版本内容组件。将大型 Dialog 的主体内容接入页面路由，保存、返回、浏览器后退共用未保存检查。现有查询与编辑状态保存在相应页面状态中。

小型确认、重命名、标签选择、文件选择继续使用小型浮层或系统选择器。主体页面保留主导航与操作位置。

`index.html` 展示三类页面、主体编辑、页面内版本保存、资产预览、明暗主题和窄屏排列。内容为示例，编辑内容保存在当前页面内存；刷新后恢复示例。文件导入、能力选择、生成执行与历史版本内容仅展示入口或位置。

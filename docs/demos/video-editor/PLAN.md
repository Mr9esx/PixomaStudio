# 视频编辑器 HTML demo

使用 writing-plans 记录工作步骤，主会话顺序执行。

目标：沿用 Studio 导航、Chat 和工作区，交付可直接打开的 HTML 文件。

- [x] 建立独立 demo 构建入口，复用现有 shadcn、AI Elements、主题和品牌资产。
- [x] 验证分镜排序、裁剪、分割、引用和撤销的状态逻辑，再接入页面。
- [x] 制作固定轨道、Remotion 预览、分镜属性、参考选择、Chat 引用与导出设置。
- [x] 支持真实本地媒体导入与视频边界帧提取；生成请求展示连接状态并可保存请求内容。
- [x] 构建单个 HTML，验证浏览器交互、文件导入、播放、窄屏和离线打开；记录交付范围。
- [x] 统一分镜和作品状态判断，关联时间轴、属性、预览、任务与导出操作。
- [x] 提供明确标识的状态预览，验证生成、重新生成、候选采用、取消、失败、首尾帧、Chat、保存和导出流转。
- [x] 压缩顶部与播放控制，将属性放进时间轴右侧；验证时间轴文字编辑、时长输入与拖动、撤销、循环播放和窄屏操作。

交付范围：本地交互 demo。示例分镜明确标识；视频生成与模型调用不伪装为真实服务结果。

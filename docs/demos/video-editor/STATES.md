# 视频编辑器状态与操作

## 分镜

视频采用状态、生成任务、首尾帧处理和资料变更分别保存，由 `shotLifecycle` 计算当前展示。时间轴、属性、预览、任务列表与作品统计复用同一结果。

| 状态 | 主要操作 | 后续状态与规则 |
| --- | --- | --- |
| 待填写 | 完善分镜 | 填写剧本或分镜说明后进入待生成 |
| 待生成 | 生成视频 | 提交后进入排队，重复提交被禁止 |
| 排队中 | 取消生成 | 收到任务开始信息后进入生成中；取消需要确认 |
| 生成中 | 取消生成 | 有当前版本时继续播放与导出；新任务独立处理 |
| 保存结果中 | 等待保存 | 首次生成按提交基线采用；已有视频的新结果进入候选 |
| 新版本待采用 | 查看新版本 | 比较后采用或保留当前版本，原资产持续保留 |
| 视频已就绪 | 重新生成 | 重新生成独立创建任务，当前视频继续使用 |
| 资料已更新 | 重新生成 | 剧本、分镜或参考改变后标记；不会删除当前视频 |
| 生成失败 | 重试生成 | 保留输入与当前视频，明确重试后建立新请求 |
| 取消中 | 等待确认 | 服务确认后显示已取消，等待期间禁止再次提交 |
| 已取消 | 继续生成或重新生成 | 根据当前是否有视频选择文案 |
| 提交结果未知 | 查询状态 | 查询原请求，不能直接再次生成 |
| 首尾帧提取中 | 等待提取 | 视频仍可播放与导出；尚不可引用对应首尾帧 |
| 首尾帧提取失败 | 重试提取 | 独立重试图片提取，保持原视频和生成记录 |
| 素材不可用 | 重新导入 | 定位到具体分镜，阻止使用失效素材导出 |

首次生成成功且提交基线未变化时自动采用。已有视频或期间修改过输入时，新结果需要选择采用。采用后同步首尾帧引用来源；下游已有图片版本持续保留。

生成中允许修改资料、调整顺序和处理其他分镜。删除生成中的分镜需要确认，已提交任务的后续结果保存在项目资产与任务记录中。

## 作品与导出

- 作品显示可用分镜数量、活动生成任务数量和待采用版本数量。
- 任一分镜存在问题，作品状态使用黄色；仍有可用视频时，单独判断是否满足导出条件。
- 首尾帧处理失败不阻止已有视频导出。新版本未采用时，导出继续使用当前版本。
- 保存中或保存失败、没有分镜、采用视频不可用时，导出检查阻止提交并提供定位。
- 导出依次经过检查、等待渲染、渲染、成功；取消与失败各自保留作品设置并提供重新导出。
- 运行中的导出使用提交快照。作品继续修改时，已有导出版本保留，新的成片需要重新导出。

## Chat 与保存

- Chat 请求排队时提供取消排队；回复中提供停止回复。
- 等待授权时显示批准与拒绝操作；批准后继续，拒绝后停止该次调用。
- 回复失败保留输入与已收到内容，提供重试；停止后保留已有内容。
- 保存区分读取中、保存中、已保存和保存失败。失败保留编辑内容并提供重试。
- 分镜引用固定到发送时的范围，切换选择不改变已提交请求。

## 状态预览入口

编辑器顶部更多菜单中的「状态预览」提供分镜、Chat、保存和导出状态选择。预览过程始终显示标识，使用「推进状态」检查流转；退出后恢复当前数据。

时间轴选中分镜后展示当前状态与主要操作。点击状态或「编辑分镜」展开时间轴右侧属性；切换分镜时属性同步切换。整片预览根据播放游标显示对应分镜状态，循环播放只检查当前分镜。

状态预览不提交网络任务、不改变项目中的采用视频，也不产生生成或导出文件。正常模式的模型与渲染连接状态继续明确展示。

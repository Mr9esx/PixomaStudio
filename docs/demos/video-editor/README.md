# Studio 视频编辑器 Demo

直接打开 `dist/index.html`，或访问本地预览 `http://127.0.0.1:5291/`。

## 可以操作的内容

- 新增、复制、删除、排序和分割分镜，撤销与重做。
- 在时间轴双击编辑剧本、分镜说明和字幕，失去焦点保存，Escape 取消。
- 在时间轴输入时长、拖动视频块右侧边缘调整时长；全部轨道同步调整，支持撤销。
- 点击「编辑分镜」展开时间轴右侧属性，播放器尺寸保持不变；双击视频块直接打开视频属性。
- 使用 Remotion 播放整片、逐帧浏览和循环当前分镜。
- 导入本地图片、音频、视频；导入视频时读取真实边界画面。
- 浏览整个项目的资产，搜索和筛选素材；预览保留浏览状态，引用时选择目标分镜。
- 裁剪视频、设置速度，将当前片段尾帧用于下一分镜首帧。
- 引用一个或多个分镜到 Chat，保存带有固定范围的对话请求。
- 切换主题、放大编辑器、调整对话宽度、切换窄屏视图。
- 保存生成请求和导出剪辑方案 JSON。
- 通过工作区更多菜单中的「状态预览」查看分镜、Chat、保存和导出的状态，逐步推进流程并检查对应操作。

编辑内容和导入素材保存在当前浏览器的 IndexedDB。HTTP 预览和直接打开 HTML 使用各自的浏览器数据空间。单个导入文件最大为 24 MiB。

## 示例内容与连接状态

初始项目「山间茶事」使用三幅分镜示意图。示例对话与示意画面均有标识。

演示没有接入对话、视频生成和成片渲染服务。正常模式可以保存对话请求、生成请求与剪辑方案。状态预览始终带有标识，不提交服务请求、不改动项目视频、不产生视频文件。

[状态与操作规则](./STATES.md) 覆盖首次生成、重新生成、取消确认、提交结果未知、候选采用、首尾帧处理、保存与导出。

## 构建与验证

使用 Node.js 22.23.2、pnpm 10.12.4。在当前目录运行：

```sh
pnpm install
pnpm build
pnpm test
```

前端复用 Studio 已安装的 shadcn、AI Elements、品牌和主题，构建依赖父工程已安装的前端依赖。新增依赖限定于此 demo 目录。生成的 HTML 包含脚本、样式和品牌图片，可离线打开。

`check-browser.mjs`、`check-states.mjs` 与 `check-layout.mjs` 使用本机 Chrome 和已有 Playwright，检查 DOM、交互与实际媒体解码，不生成截图。媒体验证使用项目缓存目录中的 FFmpeg 编码文件。

- Vite 单文件构建通过，TypeScript 检查通过。
- 十项分镜、项目资产与状态逻辑测试通过。

- 十四类状态流转检查通过，覆盖首次自动采用、重新生成保留当前视频、候选采用、任务同步、取消、未知提交、失败重试、帧提取、素材失效、资料变更、保存、Chat 和导出。

- 关闭网络后直接打开 HTML，页面、分镜和品牌图片正常读取。
- 创建新的项目视频后，项目资产库内容仍可浏览；切换分镜保留搜索条件。

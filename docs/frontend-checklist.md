# 前端与安装包验收清单

日期：2026-10-21。

## 页面源码核查

核查对象为当前 Pixoma 工程的 `web/admin/src/features/studio/` 与独立工程的 `src/features/studio/`。共同存在的业务文件仅以下三个文件存在差异，其余共同业务文件内容相同：

| 文件 | 桌面适配内容 |
| --- | --- |
| `studio-auth.tsx` | 通过 `replaceStudioIdentity` 更新身份和对应查询缓存 |
| `studio-library.tsx` | 导出请求直接触发原生保存操作 |
| `studio-workspace.tsx` | 承接模型、技能和 MCP 设置路由；补充输入等待期间继续查询会话 |

`features/agent-assets/` 的共同业务文件中，`asset-catalog.tsx` 存在路由适配：桌面目录使用 Studio 专家编辑路由；平台管理路由的入口组件由平台保留。共同存在的其他业务文件内容相同。

页面源码核查不代替实际交互检查。以下清单分别记录已有接口证据和安装包内需要完成的操作；已有检查的命令与范围见 [开发验证记录](verification.md)。

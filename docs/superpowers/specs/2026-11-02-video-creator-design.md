# PixomaStudioVideoCreator 设计方案

日期：2026-11-02。本文规定产品行为和验收条件；正式编辑器能力与需要增加的能力见第 15 节。

## 1. 作品与对话

一个视频作品保存完整脚本、分镜顺序、素材引用、工作流配置、生成记录、采用的视频和剪辑设置。作品具有稳定标识。Chat 保存创作过程，通过标识关联作品或素材。

- 一个视频默认关联一个主对话，负责脚本、分镜和整片创作。
- 素材具有自己的创作对话，例如人物“小林”、场景“茶园”、声音“旁白”。一个素材可以关联多个创作对话，每次生成结果记录来源对话。
- 同一个素材可以被多个视频引用。每次引用固定到明确的素材版本。
- 切换主对话、人物对话或场景对话，只改变左侧 Chat 内容；当前视频工作台保持打开。
- 从项目导航打开另一个视频，才切换视频作品。Chat 顶部始终显示当前对话的创作对象。
- 归档对话保留作品、素材、引用和任务。删除对话时保留必要的来源标识，作品继续可用。

项目资产库负责素材复用；视频作品负责当前成片；对话负责沟通历史。三者通过明确标识关联。

## 2. 编辑器布局与操作位置

保留现有 Chat、工作台、预览、属性面板和时间轴的布局方式。

| 区域 | 默认内容 | 主要操作 |
| --- | --- | --- |
| 左侧 Chat | 当前主对话或素材对话 | 切换对话、发送创作要求、查看生成结果 |
| 预览左侧 | 完整脚本 | 编辑脚本、在对话中创作、生成分镜、更新相关分镜 |
| 中央预览 | 当前采用的视频，支持整片播放 | 播放、定位分镜、查看候选视频 |
| 右侧属性 | 当前分镜的画面描述、参考素材、生成设置、视频版本 | 修改分镜、配置工作流、生成视频、采用版本 |
| 下方时间轴 | 分镜、参考素材、视频三条轨道 | 选择、排序、展开分镜、选择素材、剪辑视频 |
| 作品顶部 | 作品名称、保存状态、项目资产入口、导出 | 管理作品、查看资产、导出当前成片 |

脚本与视频画面同属预览区域，默认左侧显示脚本、右侧显示画面。脚本区域可收起、调整宽度；空间不足时在预览内部上下排列。Chat 切换为素材创作时，脚本与画面继续显示当前视频内容。

分镜轨道默认加高，显示编号、名称和画面描述。文本超出可见区域时提供“展开”，展开内容仍属于当前分镜；展开编辑与属性面板使用同一份草稿。编号按顺序显示，内部关联始终使用稳定的 `shotId`。

参考素材轨道显示当前分镜实际引用的素材。视频轨道显示当前采用的视频片段；尚未采用视频的位置显示“未采用视频”。候选数量放在对应分镜的视频操作入口。

单击分镜选择对象，预览定位到该分镜，脚本标记对应原文；只有用户点击“定位原文”时才滚动脚本并进入文本位置。双击分镜展开内容。多选分镜后出现批量操作工具条。

窄窗口通过已有面板收起与对象编辑入口安排内容；时间轴内部保留必要的横向滚动，页面主体不产生横向滚动。图标、字体、表面层级和组件采用现有 Pixoma 设计系统及 shadcn/ui。

## 3. 进入创作与日常操作

### 3.1 从想法开始

1. 创建视频，打开空脚本与主对话。
2. 用户直接输入脚本，或者在 Chat 描述想法。
3. Chat 给出脚本草稿，用户通过“采用脚本”写入脚本区域；用户明确要求直接修改脚本时，按指定范围写入并保留撤销记录。
4. 点击脚本区域的“生成分镜”，产生分镜提案，展示各分镜的名称、画面描述及来源原文。
5. 采用分镜后，时间轴出现分镜内容。用户配置参考素材与工作流，然后生成视频。

### 3.2 从已有内容开始

- 导入脚本：读取受支持文档，显示待采用内容，采用后进入脚本区。
- 导入视频：创建分镜，视频成为该分镜的采用版本，使用读取到的真实媒体时长。脚本和参考素材可继续补充。
- 选择项目素材：可先选择人物、场景或参考视频，再创作脚本与分镜。
- 手动添加分镜：创建稳定 `shotId`，允许直接编辑画面描述。没有脚本来源时显示“手动创建”。

每个内容区域提供本区域的动作。用户可以随时编辑脚本、创作素材、修改分镜、剪辑已有视频。

## 4. 脚本与分镜的对应关系

完整脚本使用可编辑文本块保存，每个文本块具有稳定 `blockId`。脚本修改产生修订号。分镜记录来源 `blockId` 集合、使用的脚本修订号以及当时的原文。

一个文本块可以对应多个分镜，一个分镜也可以引用多个文本块。修改文本保留 `blockId`；合并、分开或删除文本块时保存来源关系。来源无法确定时显示“检查原文关联”，交给用户重新选择，系统不根据相似文本直接改写分镜。

修改脚本后的行为：

1. 保存脚本修改。
2. 标记引用相关文本块的分镜“原文已修改”。
3. 用户点击“更新相关分镜”，查看需要更新的范围，可以选择其中部分分镜。
4. Chat 或 skill 产生修改提案，逐个显示描述变化、新增、移除和顺序变化。
5. 采用提案后，只修改选定字段。现有素材、工作流配置、视频版本和剪辑保留。

更新提案基于明确的作品版本与分镜版本。提案产生后用户继续编辑同一字段，采用时必须展示冲突，保留双方内容供选择。

删除原文不自动删除分镜。删除分镜不删除原文。用户可以在“更新分镜”提案中明确采用删除建议。

### 分镜结构操作

- 排序：只修改顺序，保留 `shotId`、视频和引用。
- 复制：创建新 `shotId`，复制描述、素材引用和工作流设置；默认不复制运行中的任务及采用视频，可明确勾选“复用当前视频”。
- 分成多个分镜：预览新的描述与顺序；采用后创建新标识。原视频保存在项目资产中；用户可以将不同视频片段分别用于新分镜。
- 合并分镜：预览合并描述和参考素材；已有片段留在资产中供选择，不自动假定这些片段能够成为单个生成结果。
- 删除：展示受影响的采用视频、运行任务和引用该分镜画面的其他分镜。删除不删除媒体资产；运行任务的结果仍进入任务记录与项目资产。

## 5. 时间轴、计划时长与真实视频时长

需要分别保存三种时间含义：

| 内容 | 来源 | 使用位置 |
| --- | --- | --- |
| 计划时长 | 用户设置，或用户采用的创作建议 | 尚未采用视频的分镜安排 |
| 生成时长 | 当前工作流的输入参数 | 生成设置和任务记录 |
| 使用时长 | 真实视频中选取的起止范围 | 成片时间轴与导出 |

尚未设置计划时长且没有采用视频的分镜，显示等宽内容卡片与“时长未定”。相关区域以分镜顺序组织，不伪装成精确秒数。已有确定时间的部分可显示自身时长；整片仍有未定项时，总时长显示“已确定时长 + 未定分镜数”。未定分镜之后的绝对时间位置暂不显示精确值。

采用视频后，该分镜使用真实媒体范围进入时间轴。所有剪辑范围按项目 fps 换算为整数帧，时长不能超出源视频范围。

拖动分镜改变顺序，参考素材与采用视频随对应分镜移动。拖动视频片段边界修改剪辑范围，不改变生成输入。成片按分镜顺序连续拼接；空白内容通过明确的空白分镜表示。

分镜画面描述卡片不要求图片。视频缩略图只出现在已经拥有视频的片段上，并来自真实视频帧。

## 6. 素材对话与跨作品复用

在分镜参考素材中提供“选择素材”和“创作素材”。

“创作素材”打开左侧对应素材 Chat。首次创建时传入素材类型、创作要求和需要的分镜上下文。已有素材允许继续原对话，也允许创建新的创作对话；新对话仍关联同一个素材标识。

Chat 顶部显示“人物 · 小林”，并提供“返回视频对话”。切换过程保留视频选择、脚本草稿、时间轴缩放、滚动位置和播放位置。输入框中的未发送内容按对话保存。

素材 Chat 获得当前素材说明、选定版本和本次相关上下文。视频主对话获得素材信息、固定引用版本及选定的创作要求；完整素材对话历史留在素材对话中。

素材结果保存为新版本后，提供两个明确动作：

- “用于当前分镜”：修改当前分镜的素材引用。
- “用于其他分镜”：显示当前作品内引用相同素材的分镜，列出各自版本，由用户勾选范围。

批量默认选中与当前分镜引用相同旧版本的项目；已经使用其他版本的分镜保留原选择。其他视频的引用更新通过资产详情的使用位置列表单独选择。

生成素材新版本只增加资产版本。使用者继续引用原版本，直到用户采用更新。已引用或被任务快照引用的媒体版本必须保持可读取；移除项目中的素材入口不删除被引用的版本。

### 对话操作的目标

发送消息前，输入框显示目标，例如“当前视频”“分镜 03”“人物 · 小林”。目标在发送时固定。发送后改变时间轴选择，不改变这条消息的目标。

从素材对话产生的结果默认进入素材候选。将其应用到视频时，需要明确的分镜标识与引用范围。通过对象标识传递上下文，不通过名称猜测目标。

## 7. 工作流与生成输入

分镜属性中的“生成设置”包含已发布工作流、固定的工作流版本、输入字段、输出类型和参数校验结果。只允许选择能够产出视频的工作流。

当前分镜实际提交的输入需要完整可见。输入来源可以是：分镜描述、素材版本、上一分镜画面、手工输入。

- 分镜描述可以映射为文本输入，或者通过 Chat 编写为生成提示词。
- 素材引用可以仅用于创作，也可以映射到工作流输入字段。映射时校验字段类型与数量。
- 每个自动关联字段记录来源和修订号。来源修改后，显示待更新内容，由用户采用到实际输入。
- 用户手动改写字段后保留该文本。后续分镜描述变化产生更新建议，不覆盖手工编辑。
- 生成时显示最终解析后的输入值及所用版本，不依赖模型重新猜测。

切换工作流时，保留各工作流版本对应的参数草稿。字段不匹配时显示需要重新选择的输入；当前采用视频继续保留。工作流发布新版本只提示可更新，当前分镜继续固定原版本。

批量设置工作流时选择明确的分镜范围；字段映射和类型校验逐个执行。存在问题的分镜显示具体字段，用户可以补充，或明确选择只提交可生成的分镜。

## 8. 状态与修改影响

每个分镜分别保存创作内容、输入配置、任务记录和采用视频。界面按当前问题显示必要标记，不将这些状态压缩成一个进度数字。

| 事件 | 当前视频 | 提示与后续动作 |
| --- | --- | --- |
| 修改脚本原文 | 保留 | 相关分镜显示“原文已修改”，可更新描述 |
| 修改分镜名称或顺序 | 保留 | 更新名称或顺序 |
| 修改画面描述 | 保留 | 关联的生成文本显示“描述待同步” |
| 采用描述到生成输入 | 保留 | 若与该视频的任务输入不同，显示“生成输入已修改” |
| 人物生成新版本 | 保留 | 参考素材显示“有新版本” |
| 采用新的创作参考，但未映射输入 | 保留 | 更新创作参考关系 |
| 更新映射到工作流的素材版本 | 保留 | 显示“生成输入已修改” |
| 改变工作流版本或生成参数 | 保留 | 显示“生成输入已修改” |
| 剪辑、音量或播放顺序变化 | 保留 | 更新成片编辑状态，不要求重新生成 |
| 新结果返回 | 保留 | 显示“有新候选”，可预览和采用 |
| 任务失败、取消或断开页面 | 保留 | 根据真实任务状态显示重试、查看任务或重新连接 |

已有视频是否符合当前生成输入，通过该视频关联的任务快照与当前有效输入比较。比较内容包括工作流版本、输入值、固定素材版本及影响生成的设置。采用稳定序列化规则；字段排列变化不构成内容变化。

外部导入视频没有生成快照，标记“导入视频”。编辑分镜时不声称该视频与某次生成输入一致。

## 9. 生成任务与候选视频

“生成视频”作用于当前分镜；多选后提供“生成所选视频”。提交窗口显示目标分镜、所用工作流、缺失参数、参考素材版本和真实可获取的用量信息。服务未提供预估时不显示推测金额。

提交任务前保存当前作品及实际输入，并生成不可变请求快照：作品标识、分镜标识、作品修订号、工作流及版本、输入值、素材版本、来源修订、请求标识。

一个分镜同一时间保留一个活动生成任务；不同分镜允许并行。生成过程中仍可编辑下一次输入，当前任务继续使用提交时的快照。任务记录能同时显示“本次输入”和“当前编辑内容”。

所有生成结果进入候选列表，通过“采用此版本”进入成片。首次生成也采用相同规则。候选记录所属分镜、任务、生成输入、时长与创建时间。任务产生多个视频时，逐个成为可选择候选。

候选预览时，中央预览标注“候选预览”，提供“采用此版本”和“返回当前视频”；时间轴的采用版本保持原状。

任务行为：

- 重复点击提交通过请求标识去重。
- 网络中断时记录查询错误，保留原任务与下游依赖等待；连接恢复后继续查询原请求，确认结果后恢复显示。
- 取消任务以服务确认结果为准。“停止等待”只停止当前界面等待，不显示“任务已取消”。
- 取消入口按提供方及当前执行状态开放。请求发送前读取最新状态，已经结束的任务返回实际结果。取消请求明确被拒绝时清除正在取消的标记；结果尚未确认时保留查询入口。
- 失败重试默认使用原任务快照；“使用当前设置重新生成”提交新的快照，两种操作分别命名。
- 编辑器关闭或停止界面等待后，作品任务继续由后台查询和保存结果；重新打开读取实际状态。应用退出后保留原任务标识，下次启动继续处理。
- 结果按 `shotId` 与任务标识归属，返回顺序不改变分镜顺序。
- 分镜已经删除时，结果进入项目资产与任务记录，不重新创建分镜。
- 返回结果缺少可用媒体或有效时长时显示具体错误，不创建可采用视频。

## 10. 采用视频、时长变化与历史版本

一个分镜同时保存当前采用视频、候选视频和历史采用版本。采用新版本会把原视频及其剪辑设置保存到历史记录。

点击“采用此版本”后：

1. 校验媒体可访问、时长已知、目标分镜存在以及当前作品版本。
2. 显示当前与新视频的使用范围。
3. 已有采用视频时默认保留当前使用时长。新视频足够长时，可选择起点，范围必须有效；新视频较短时，要求用户选择缩短该分镜，或取消采用。
4. 用户也可以选择“使用完整视频”，明确改变分镜使用时长。
5. 首次采用时默认使用完整视频；如果已有计划时长，同时提供按计划选取有效范围的选项。
6. 时长改变时，显示该分镜时长、成片总时长及后续分镜开始时间的变化，然后一次性采用。

视频、分镜和参考素材三条轨道随对应分镜一起更新。剪辑与采用操作都支持撤销；撤销恢复数据，不撤销已经消耗的生成任务。

恢复历史采用版本时可以恢复当时的剪辑范围。分镜描述和当前生成参数保持当前内容；若历史视频对应的输入不同，继续显示“生成输入已修改”。用户另行选择恢复生成设置时，展示将变化的字段。

### 前后分镜画面引用

引用其他分镜的首帧、尾帧或选定画面时，记录来源分镜、来源媒体版本、源视频帧位置和画面资产版本。

“采用视频的尾帧”以该分镜实际使用范围的最后一帧计算。改变采用视频或改变剪辑终点，都可能改变这个来源。下游分镜显示“来源画面已更新”，由用户选择保留原参考或采用新画面。

采用新画面后，只更新对应引用及其映射输入。下游已采用视频保留；继续生成需要明确操作。仅调整分镜顺序不改变已经指定的来源分镜。批量任务若明确要求使用本次新生成的前镜画面，任务计划必须展示依赖顺序；存在循环引用时阻止该批量提交并指出相关分镜。

使用本次生成结果作为下游参考，需要用户在批量提交时明确选择。上游结果可用后，确定输出媒体与画面版本，再冻结下游实际请求快照并提交。上游具有多个输出且未指定目标时，等待选择输出；上游失败或取消时，依赖它的任务保持未提交，并显示原因。这个引用动作不自动采用上游视频到成片。

## 11. 自动保存、冲突与恢复

- 文本编辑保留草稿。编辑状态随作品保存，关闭前等待保存结果；保存失败显示可重试反馈，草稿继续保留。
- 分镜结构预览保留尚未采用的名称、描述、原文与参考选择，支持重新打开。来源变化时保留草稿并阻止采用；明确放弃后可以重新预览当前分镜。
- 每次写入带基础版本与请求标识。不同对象的独立修改可合并，同一字段冲突显示双方内容。
- AI 提案与人工编辑遵循同一版本校验。旧提案不能覆盖更新后的引用、工作流、采用视频或剪辑。
- 正在输入的文本不因后台任务返回而重置。任务结果只更新任务与候选记录。
- 切换素材 Chat 不卸载视频作品。关闭作品前保存草稿；保存失败时保留恢复入口。
- 撤销只处理创作与剪辑操作，任务状态和媒体生成记录继续按照服务真实状态更新。
- 在作品恢复记录中打开历史内容，采用前展示修改范围；恢复操作产生新的作品修订，不复用旧的请求标识。

## 12. 导出

导出使用当前采用的视频版本、顺序、剪辑范围与作品输出设置。

缺少采用视频、媒体不可读取、剪辑范围无效、保存冲突未处理时，阻止导出并定位到具体分镜。尚未采用的候选、正在运行的任务不进入导出内容。

当前生成输入有修改但采用视频仍有效时，允许导出。导出窗口列出相关分镜，并明确显示“使用当前已采用版本”，由用户确认本次成片内容。

用户提交导出后冻结作品快照，记录媒体版本、剪辑范围和作品修订号。导出期间继续编辑不会改变该次任务。结果记录来源作品版本，并提供打开对应作品快照的入口。

新作品使用分镜、参考素材和视频三条轨道。已有作品的字幕与独立音频数据保留原有效果，通过“已有内容”入口查看、调整或明确移除；导出检查列出这些内容，防止打开旧作品后产生无法察觉的成片变化。

## 13. PixomaStudioVideoCreator skill

skill 根据当前对象和用户动作调用现有创作、资产及工作流能力。每次开始时读取作品的最新保存状态和目标对象，不依赖对话中早期描述推断当前数据。

支持的意图：

1. 创作、改写或采用完整脚本。
2. 根据指定脚本范围产生或修改分镜。
3. 为指定分镜寻找已有素材，或进入关联素材对话创作。
4. 为指定分镜选择已发布工作流、配置实际输入。
5. 按用户指定范围提交生成、查询任务、重试或取消。
6. 展示候选差异，按用户指令采用视频及剪辑范围。
7. 根据当前采用版本检查并提交导出。

内容修改可以生成可采用提案；用户明确授权直接修改时，执行限定范围的修改并记录撤销信息。生成、批量替换、视频采用和导出都必须有明确目标与范围。用户已经明确指定动作、输入与范围时，不重复询问同一事项。

每个修改结果包含目标标识、基础版本、字段修改和影响对象。每个生成结果关联请求快照。素材创作结果包含素材标识、版本、来源对话和本次可应用的引用位置。

`studio_read_video_project`、`studio_write_video_project`、`studio_update_video_shot` 承担作品读取及编辑；`studio_propose_video_script` 与 `studio_propose_video_storyboard` 保存可采用提案。素材工具读取对象和登记结果；生成工具提交单个分镜或批次、查询记录、选择依赖输出、取消等待及使用原输入再次生成。导出工具使用固定作品快照并查询历史。没有支持的动作必须返回明确的不可用原因。

## 16. 必须验证的场景

1. 手写脚本、Chat 创作脚本、导入脚本都能形成同一个可编辑脚本对象。
2. 修改局部原文只提示相关分镜；用户可以只更新其中部分分镜。
3. 采用分镜修改提案后，原有视频、素材、工作流和剪辑仍然保留。
4. 脚本删除、文本块合并或分开后，关联状态可解释且可以重新指定。
5. 切换人物对话并返回后，作品、选择、文本草稿和播放位置保持。
6. 人物产生新版本后，所有既有引用仍使用原版本；批量更新严格遵循选定范围。
7. 创作参考变化与实际工作流输入变化产生不同的状态。
8. 提交生成后继续编辑输入，返回结果仍显示提交时使用的内容。
9. 同一分镜重复点击不会重复提交；不同分镜返回顺序不改变对象归属。
10. 生成失败、取消、页面关闭和网络中断均保留当前采用视频。
11. 新候选预览不改变成片；采用后能撤销恢复原视频与剪辑。
12. 新视频长于、等于、短于原使用时长时，范围选择及后续时间变化均正确。
13. 改变上游采用视频或剪辑终点，只提示实际引用对应画面的下游分镜。
14. 删除分镜后返回的任务结果仍可从资产与任务记录访问。
15. 人工编辑与 AI 提案冲突时，双方内容均可查看且不会相互覆盖。
16. 工作流发布新版本时，已有分镜与历史任务仍能解释各自使用的版本。
17. 媒体读取失败或时长未就绪时，阻止采用并显示明确原因。
18. 导出使用提交时的采用版本；导出期间的新编辑和新候选不改变结果。
19. 旧作品打开与导出后，已有字幕和音频保持原有效果，明确移除才改变结果。
20. 所有状态通过真实服务与真实媒体验证；服务未连接时显示不可用原因。

# 桌面窗口与页面布局

日期：2026-10-26。用户已确认本设计。

- 主体页面由同一个 `StudioPage` 容器提供外边距、圆角、边框和 `bg-card` 表面。覆盖新对话、已有对话、资产库、三个市场、全部设置和专家编辑页面。
- 页面顶部使用统一的 64px 最小高度、水平间距和分隔线。资产库保留文件树与工具栏，使用相同的顶部高度。
- macOS 使用 Tauri `Overlay` 标题栏，隐藏标题文字，保留原生窗口按钮。左侧导航为窗口按钮预留空间；窄窗口和独立编辑页面的操作区域为窗口按钮预留空间。
- 页面顶部空白和导航顶部支持拖动窗口，双击行为由 Tauri 提供。按钮、输入框和其他可操作元素保持原有行为。
- 登录、注册、加载与错误页面也保留可拖动区域。窗口样式跟随应用主题。
- 验证使用类型检查、已有测试、前端构建、Tauri 配置验证与原生应用运行检查；使用文本和结构核对页面。

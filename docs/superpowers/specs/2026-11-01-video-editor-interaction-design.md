# 视频编辑器交互设计

- 日期：2026-11-01。
- 产品范围：PixomaStudio 视频编辑器及其与 Chat、项目资产、生成任务的交互。
- 文档状态：已确认并开始实现；功能实现与运行验收另行记录。
- 实现依据：`src/features/studio/video-editor.tsx`、`video-timeline.tsx`、`video-editor-model.ts`、`studio-chat.tsx`，以及 `src-tauri/src/video_project.rs`、`video_export.rs` 和 `tools.rs`。
- 工作区采用紧凑的视频编辑布局。组件复用 shadcn/ui，颜色使用 Pixoma 语义令牌，媒体继续使用已有资产版本管理。

## 1. 核心用户故事（User Story）

### 1.1 开始创作与组织内容

- **US-01 创建作品**：As a 视频创作者，I want to 创建空白作品并设置名称、画幅和帧率，So that 我能按发布要求开始制作。
- **US-02 想法生成剧本**：As a 视频创作者，I want to 双击「添加剧本」并输入想法，通过 Chat 调用剧本 Skill，So that 生成内容能够直接写入指定分镜。
- **US-03 整片创作**：As a 视频创作者，I want to 从完整创意生成整片剧本及有序分镜，So that 我能继续逐镜调整和生成素材。
- **US-04 手动编写与改写**：As a 视频创作者，I want to 直接编辑剧本或把选中内容交给 Chat 改写，So that 我能控制修改范围并保留其他内容。
- **US-05 分镜表达**：As a 视频创作者，I want to 分别编辑剧情、画面描述、分镜图和计划时长，So that 每个分镜能够清楚表达拍摄与生成要求。
- **US-06 分镜组织**：As a 视频创作者，I want to 新增、复制、排序、分割和删除分镜，So that 我能调整叙事顺序及节奏。

### 1.2 资产查找与使用

- **US-07 导入素材**：As a 视频创作者，I want to 一次导入多个素材并查看逐项结果，So that 我能快速准备作品资料。
- **US-08 查找素材**：As a 视频创作者，I want to 按名称和类型筛选项目资产，So that 我能在大量素材中找到目标。
- **US-09 查看素材**：As a 视频创作者，I want to 预览资产内容、版本和媒体信息，So that 我能判断素材是否适用。
- **US-10 拖放素材**：As a 视频创作者，I want to 将资产拖入对应分镜和轨道，并看到目标位置与用途，So that 我能直接建立参考或采用素材。
- **US-11 管理参考**：As a 视频创作者，I want to 查看、替换、移除参考并设置用途，So that 生成任务能使用正确的角色、场景、首尾帧或声音资料。
- **US-12 引用到 Chat**：As a 视频创作者，I want to 把资产、分镜或整片加入 Chat，So that 模型能理解我正在讨论的具体对象。

### 1.3 编辑与预览

- **US-13 视频剪辑**：As a 视频创作者，I want to 调整视频源范围和使用时长，So that 成片只保留需要的内容。
- **US-14 字幕编辑**：As a 视频创作者，I want to 在字幕轨道编辑对应分镜的字幕，So that 字幕内容与该分镜画面一致。
- **US-15 音频编辑**：As a 视频创作者，I want to 添加、移动、裁剪、循环和调节成片音频，So that 声音能配合作品节奏。
- **US-16 时间轴定位**：As a 视频创作者，I want to 缩放时间轴、适应全部内容、开关吸附并跳转时间，So that 我能准确编辑长短不同的片段。
- **US-17 播放控制**：As a 视频创作者，I want to 播放整片或当前分镜、逐帧检查、调节监听音量和全屏查看，So that 我能判断剪辑与声音效果。
- **US-18 独立选择**：As a 视频创作者，I want to 在保持播放位置的情况下选择对象和查看属性，So that 检查内容不会打断当前定位。
- **US-19 对象属性**：As a 视频创作者，I want to 只看到所选对象相关的字段和操作，So that 我能快速修改正确内容。
- **US-20 工作区调整**：As a 视频创作者，I want to 调整和收起面板，并恢复上次布局，So that 我能根据窗口空间安排编辑区域。
- **US-21 键盘操作**：As a 高频编辑者，I want to 使用快捷键、焦点导航和菜单完成编辑，So that 我能减少重复指针操作。

### 1.4 生成、保存与交付

- **US-22 生成视频**：As a 视频创作者，I want to 为分镜选择工作流、补充参数并查看任务进度，So that 我能获得与分镜要求相符的视频。
- **US-23 采用版本**：As a 视频创作者，I want to 预览候选、采用版本并保留历史，So that 我能比较生成结果并恢复选择。
- **US-24 保存恢复**：As a 视频创作者，I want to 确认作品保存状态并在重新打开时恢复内容，So that 编辑过程可以连续进行。
- **US-25 撤销重做**：As a 视频创作者，I want to 按完整编辑动作撤销和重做，So that 我能恢复内容、时长及关联引用。
- **US-26 并发处理**：As a 视频创作者，I want to 在 Chat 或其他窗口修改同一内容时核对差异，So that 我的手动输入得到保留。
- **US-27 导出成片**：As a 视频创作者，I want to 检查作品、定位阻碍导出的问题并导出成片，So that 我能播放和保存可用的视频文件。
- **US-28 失败恢复**：As a 视频创作者，I want to 获知导入、生成、保存和导出失败的具体原因并重试，So that 我能继续制作并保留已有成果。
- **US-29 剧本转为提示词**：As a 视频创作者，I want to 根据当前剧本编辑待采用提示词并选择目标参数，So that 我能确认内容后更新生成设置并保留其它参数。

## 2. 信息架构与页面流转（UI/UX Flow）

### 2.1 主工作区

- **入口**：项目内会话 →「视频编辑器」。沿用当前会话与作品关系，资产库展示可访问的项目资产。
- **作品工具栏**：名称与规格、整片创作、整片对话、剧本请求状态、保存、撤销、重做和导出。
- **Chat 区**：常驻工作区左侧，宽度可以调整；保留消息、输入草稿、引用和排队请求。
- **上方编辑区**：一行 Tab 切换「预览」和「项目资产」，共用同一内容区域；切换到项目资产暂停预览并保留播放位置。对象编辑在宽窗口中使用右侧内部面板，默认宽度 280px，可调整宽度。恢复布局入口放在工作区域标题行。
- **上下分隔条**：位于上方编辑区与时间轴之间，使用单条 1px 线，可用指针和键盘调整，双击恢复默认比例。
- **下方时间轴**：轨道顺序为剧本、分镜、参考资产、视频、字幕、成片音频。参考块展示图片、音频或视频类型及用途；成片音频可展开多行以展示重叠片段。
- **属性区**：双击对象或选择右键菜单的编辑操作后打开；内容只对应目标对象。生成设置、生成按钮、任务状态和分镜对话放在分镜编辑区域，按钮明确显示「生成此分镜」。时间轴贯穿下方整行。
- **时间轴工具栏**：保留新增分镜、吸附、适应全部、缩放；分镜右键菜单提供编辑、定位、复制、分割和删除整个分镜。音频右键菜单提供编辑、定位和移除。生成中的分镜禁止分割和删除。
- **紧凑布局**：取消时间轴块之间的装饰间距和独立圆角边框；横向线分隔轨道，纵向线分隔相邻分镜。选中对象有清晰焦点及选中提示。
- **轨道显示**：轨道标题菜单提供收起、展开，以及紧凑、中等、较高三种高度，分别为 42、64、96px。收起后保留 28px 的对象条及选择入口；展开恢复此前高度，编辑文字时自动展开。较高轨道显示多行文字。显示设置按会话保存，恢复布局同时恢复默认轨道显示，不修改作品内容。
- **尺寸**：作品工具栏高 40px，预览控制条高 36px，轨道标题宽 96px；时间轴默认占编辑区高度的 40%。可见分隔线为 1px，指针操作范围为 8px。
- **字体**：面板标题 12px、600 字重，普通字段 12px，长文本输入 13px，辅助信息 11px；时间和数字使用等宽排列。
- **资产卡片**：缩略图、名称、必要信息纵向排列；更多菜单位于缩略图右上方。支持网格和列表视图，窄面板自动减少列数。
- **窄窗口**：对象编辑通过同一标题行的「对象编辑」Tab 替换上方内容；预览、资产和对象编辑均位于编辑器内部，时间轴始终可见。只有时间轴内部可以水平滚动。
- **前置状态**：读取会话、作品与可用资产；读取期间显示加载状态并阻止修改。
- **后置状态**：空作品显示创作入口；已有作品恢复保存内容、选择对象、预览位置和布局。读取失败显示重试，保留可以恢复的草稿。

### 2.3 对象属性

- **剧本**：剧本文字、用 Chat 改写、关联生成消息。
- **分镜**：名称、剧情对应关系、画面描述、分镜图、计划时长、排序与复制删除。
- **参考资产**：名称、版本、用途、关联输入字段、预览、替换、移除、引用到 Chat。
- **视频**：采用版本、源开始位置、使用时长、原声音量、候选与历史、生成入口。
- **字幕**：字幕内容及所属分镜。字幕显示范围随所属分镜，输入中支持换行；生成剧本不会自动填入字幕。
- **成片音频**：具体音频名称与版本、开始位置、源开始位置、时长、音量、循环、移除。
- **未选择对象**：显示作品规格和可用编辑入口。

## 3. 完整业务逻辑与规则

### 3.1 正向主流程（Happy Path）

1. 打开项目会话，读取作品；新作品填写名称和规格，进入固定轨道工作区。
2. 输入整片想法或双击目标分镜的「添加剧本」，确认范围和剧本 Skill 后提交。
3. 编辑器保存当前有效修改，把想法、目标 ID、基线内容和 Skill 版本交给当前 Chat。现有 Chat 草稿保持原值。
4. Chat 按现有队列和权限流程运行，读取作品后生成内容；通过现有视频项目工具写入允许的对象和字段。
5. 服务端检查目标、范围和修订，成功后返回新版本；编辑器刷新对应剧本和分镜，保留播放位置。
6. 导入并查找真实素材，将图片或声音拖入参考轨道，选择用途；将视频拖入视频轨道采用，或拖到末尾创建分镜。
7. 为需要生成的分镜选择工作流，核对提示词、参考和必填参数；提交后在分镜和 Chat 中查看状态。
8. 生成成功后预览候选并采用；手动素材、现有视频及历史版本保持可访问。
9. 调整分镜顺序、源范围、时长、字幕和音频；通过整片与分镜预览检查画面和声音，必要时撤销或重做。
10. 打开导出检查，处理所有阻止导出的项目；保存当前修订后提交不可变快照，导出成功后播放或保存成片。

### 3.2 选择、编辑与时间规则

- 单击只选择时间轴对象，不打开编辑面板、不改变播放位置。点击标尺、拖动游标、时间输入、上一分镜和下一分镜改变播放位置。
- 双击空剧本打开创作想法；双击已有剧本或字幕进入直接编辑；双击其它轨道对象打开编辑器内部的对象面板；双击素材进入资产预览。Enter 提供对应键盘入口。
- 右键选择目标并显示该对象的操作菜单，菜单操作始终使用目标对象 ID。分割位置必须在目标分镜内部；删除整个分镜与移除音频使用明确动作名称，并保留撤销能力。
- 一次连续文字编辑、一次拖动或一次素材采用形成一条撤销记录；Escape 取消当前未提交编辑。
- 撤销和重做恢复编辑内容，同时保留最新生成请求、任务关联与生成输入基线。等待生成或任务状态尚未确认时，禁止通过历史操作移除目标分镜；明确停止等待后允许移除。任务状态更新和后台候选收集不增加编辑历史，也不清除重做记录。撤销视频采用保留已经生成的候选和历史素材。
- 属性数值使用独立输入草稿，Enter 或失去焦点时校验并提交；Escape 取消本次输入。空白、非法数字或超出有效范围时保留原输入，字段下方显示错误，作品数值保持不变。输入草稿按会话、对象及字段恢复。
- 分镜名称使用独立输入草稿，提交时去除首尾空白；空白名称保留在输入框并显示字段错误，作品继续使用有效名称。名称草稿按会话和分镜恢复，提交、取消与数值输入使用相同操作。
- 时间轴剧本和字幕输入按会话保存目标、原始内容及当前文字。正常失去焦点时只提交对应字段；同字段更新后保留草稿，显示当前内容和可编辑草稿，由用户选择采用内容。目标删除后保留文字，支持明确放弃或保存为片尾的新分镜；新分镜使用独立标识，保留原名称，只写入对应文字字段。恢复前检查分镜数量和内容限制，失败继续保留草稿。
- 属性提交前比较编辑基线：同一字段已更新时提供「使用最新内容」与「保留输入」；保留输入仍需满足当前作品和素材范围。未应用输入通过作品工具栏定位，处理完成后才能生成或基于当前作品创建导出快照。
- 新增和复制插入当前分镜之后；没有选择时追加。复制生成新 ID，复用素材版本和编辑设置，保留原对象，生成任务归属保持独立。
- 分割位置必须在分镜内部并满足两侧至少一帧。两部分共享源素材、分别保存源范围；字幕内容分别保留，成片音频保持作品时间。
- 删除分镜移除编辑引用，保留原始资产和生成历史；删除参考只解除引用。删除成片音频只移除所选音频片段。
- 分镜时间边界按项目帧率计算，区间采用 `[start, end)`；秒数在边界处换算成整数帧。至少保留一帧，禁止负数、非有限数和越过源素材范围。
- 修改帧率时重新计算帧边界，并展示受影响的总时长；确认后作为一个可撤销操作保存。
- 缩短作品导致音频范围变化时，在 F12 列出具体影响；确认后应用，撤销同时恢复分镜与音频。
- 关闭音频循环时检查素材剩余时长。片段需要缩短时，在 F12 展示原时长、调整后时长及播放方式，确认后一次提交；取消保留原值。素材时长未知或可用范围不足一帧时拒绝修改。确认期间作品发生变化时重新检查，保留当前作品。
- 字幕跟随分镜；成片音频使用作品绝对时间。移动分镜时字幕同步移动，音乐维持原时间位置。
- 监听音量只影响预览设备；视频和成片音频的音量属于作品内容，参与导出。
- 当前分镜预览包含相交的成片音频。切换预览来源保存原播放帧，并暂停原媒体，防止多个预览同时发声。
- 视频或音频读取及媒体缓冲期间保持播放帧，显示素材读取状态；读取完成后按照当前播放意图继续，用户已经暂停时保留暂停状态。等待期间可以定位其它分镜，离开原片段后释放其等待句柄。无法识别的素材地址立即显示读取错误。
- 全屏预览提供播放、暂停和退出控制；退出后使用编辑器控制条。读取错误界面位于播放器容器内，提示文字和操作按钮保持界面尺寸，随播放器进入全屏；错误期间提供重新读取与退出全屏操作。
- Space 播放暂停，方向键逐帧，Home/End 定位开始和结束，Delete 删除当前对象，Cmd/Ctrl+Z 撤销，Cmd/Ctrl+Shift+Z 重做，Cmd/Ctrl+D 复制分镜。文本输入期间使用原生编辑快捷键。

### 3.3 资产、参考与拖放规则

| 拖动对象 | 目标 | 结果 |
|---|---|---|
| 图片 | 分镜轨道中的分镜 | 设为分镜图，保存确切版本 |
| 图片、音频、视频 | 参考资产轨道中的分镜 | 打开用途选择，登记参考 |
| 视频 | 已有视频块 | 采用该版本；已有采用视频进入历史 |
| 视频 | 时间轴末尾或空作品的视频轨道 | 创建分镜并采用视频，时长使用可读取的素材时长 |
| 音频 | 成片音频轨道 | 按目标时间创建片段，默认不循环，范围限制为素材与作品可用长度 |
| 文本资产 | 剧本轨道 | 读取内容并展示采用预览；确认后写入目标剧本 |
| 任意可访问资产 | Chat 引用入口 | 加入具体资产版本引用，保留原输入草稿 |
| 不匹配的类型 | 任意轨道 | 显示不可放置；不修改作品 |

- 拖放、菜单和属性中的同类操作调用同一业务入口；指针进入、离开、取消和放置都有明确反馈。
- 文件类型同时检查扩展名、媒体类型和实际解码结果。图片接受可解码 PNG、JPEG、WebP；音视频接受媒体探测与编辑器解码共同支持的文件；文本接受有效 UTF-8 文本和 Markdown。失败不创建可用媒体条目。
- 重复导入以内容摘要与媒体格式识别；检查当前项目中未归档资产的全部版本，复用匹配的内容版本并显示「已存在」。同名不同内容创建独立资产，不同项目分别登记；已有资产的「导入新版本」入口创建该资产的新版本。导入结果可以直接查看确切版本，资产名称及已有项目信息保持原值。每个导入项使用固定请求标识，失败重试沿用该标识；请求内容变化时拒绝复用标识。
- 生成参数上传在开始时绑定分镜、工作流及发布版本、输入字段和该字段的原值。完成后仅在目标与原值保持一致时写入返回的确切资产版本；切换所选对象不改变上传目标。目标删除、工作流变化或用户重新选择参数后，保留已导入资产并提示从项目资产重新选择，当前输入保持原值。同一素材引用按资产与版本标识比较，JSON 字段顺序不构成冲突。上传期间该分镜显示导入状态并等待导入结束后生成，其它分镜保持可操作。
- 分镜视频导入保存开始时的分镜 ID、采用视频的资产与版本、源开始位置和使用时长。返回后检查这些字段，变化时保留当前内容与已导入资产，提示从项目资产重新选择。其它文字、参数、音量、任务及候选更新继续保留；重复导入已采用的同一版本保留当前剪辑范围。只接受具有有效时长的视频版本。
- 文件控件在接收选择后清空原生文件值，允许再次选择同一文件进行重试或导入到另一目标。
- 同一分镜中，相同资产版本和相同用途的参考保持单项。不同用途可以分别引用。
- 参考保存独立于工作流输入。生成前按照工作流声明选择输入字段，验证类型与数量；多个字段符合时让用户明确选择。
- 添加参考的确认窗口显示目标分镜、资产名称和固定版本；生成字段来自该目标分镜的工作流版本。选择字段时保存该字段原值，确认前检查分镜、工作流版本、参数原值和资产版本；冲突错误在窗口内展示，保留用途选择并提供重新选择参数入口。当前项目存在编辑冲突时，处理完成后才能确认采用。
- 首尾帧引用保留来源分镜与媒体版本。来源采用版本变化后标记引用需要核对，用户可以更新引用或继续使用原版本。
- 参考音频作为生成资料；只有明确加入成片音频后才参与混音。

### 3.4 Chat、生成与写回规则

- 编辑器请求绑定 `sessionId`、目标分镜 ID、操作范围、允许字段和 Skill 版本；界面选择变化不改变已提交请求。
- 剧本 Skill 使用当前会话权限允许的技能。编辑器记住明确选定的 Skill；没有可用选择时，阻止提交并保留想法，提供技能选择或安装入口。
- 分镜请求只能修改目标分镜获准字段；整片请求允许新增和调整明确指定的分镜。服务端检查范围，不能仅依赖提示词约束。
- 原始想法、排队状态、运行消息和结果可追溯。同一 `request_id` 重复提交返回已有请求。
- 写回时比较提交基线与当前目标字段：目标字段未变化则应用结果；不同字段的修改合并；相同字段变化进入 F13。
- 任务期间目标被删除后，结果进入对应消息或任务记录，不重新创建被删除的分镜。
- 剧本和生成提示词分别保存。使用「根据剧本更新提示词」生成待采用内容，明确采用后更新参数；手动参数保持原值直到用户采用。
- 待采用内容直接读取当前剧本文字，允许用户继续编辑；只选择文字输入，已有 `prompt` 字段可作为初始目标，其它字段需要明确选择。草稿按会话、分镜、工作流和版本分别保存，关闭窗口保留草稿。剧本或目标参数变化时核对基线，重新读取剧本会更新草稿；保留输入会以当前内容作为新基线，随后仍需点击采用。
- 首次视频生成只有在目标及生成输入保持一致时自动采用；已有视频或输入变化时，结果进入候选。所有结果均登记真实资产版本。
- 生成参数按固定工作流版本的 JSON Schema 检查类型、范围、枚举、文字规则、引用和组合条件。字段问题显示在对应控件下方，跨字段组合问题显示在生成设置中；提供问题数量及焦点定位，存在问题时禁止新建生成请求。校验不修改输入，也不自动填入默认值。提交前按同一工作流版本重新检查参数和实际素材。
- 一个生成请求完成前，重复点击显示当前任务；重新生成使用新的请求 ID。取消后等待服务端确认，提交结果未知时先查询原请求。
- 取消等待与取消服务端任务分别表达；界面离开不被解释为任务取消。

### 3.5 保存、布局与导出规则

- 作品内容复用现有 `video-project.json.md` 资产快照保存；`asset_version` 用于并发检查，`version` 表示文档格式。
- 读取成功后才能编辑。保存状态显示读取中、未保存、保存中、已保存、失败或冲突，失败保留草稿。
- 每次有效业务操作进入历史，并触发自动保存；保存请求按会话顺序执行，旧响应不能把更新后的内容标记为已保存。
- 会话切换前提交有效修改；保存失败停留并打开 F15。意外退出后提供本地草稿恢复，草稿按会话和作品版本归属。
- 关闭窗口与退出菜单复用同一保存检查。退出前结束当前字段输入，保留位置、属性草稿和未发送的创作想法；有文字编辑冲突时停留并显示 F15。保存期间内容变化时保留窗口；重复退出请求合并检查，保存期间切换编辑器后检查当前编辑器。明确放弃时清除相应草稿。界面退出监听就绪后启用原生事件保护，确认退出使用一次原生退出操作。
- 外部内容更新保留本地编辑；服务端重新检查版本后写入合并结果，不能直接覆盖整个作品。
- 布局尺寸、搜索、预览模式、选择与播放位置属于编辑器状态，独立于作品历史保存；恢复布局不修改作品内容。
- 资产预览按会话保存资产 ID、固定版本 ID 和素材播放时间，与整片及分镜播放位置分别保存。重新打开后读取实际资产，恢复到暂停状态；素材时间超过实际时长时定位到片尾。版本失效时保留选择并提供版本入口，读取失败时提供重试；返回视频预览保留此前整片或分镜的位置。
- 素材文件读取与解码失败在对应预览区域显示错误；缩略图单独显示读取失败，编辑内容继续保留。整片预览重试重新读取该预览使用的素材，保留当前播放帧与源范围，恢复后保持暂停。素材预览重试保留该素材的位置；参考图片和候选视频分别提供读取错误及重试入口。Blob URL 随读取结果变化更新，区域卸载时释放。
- 尺寸必须是 16–4096 的偶数整数，帧率为 1–60 的整数；分镜及音频片段分别最多 100 项，作品最长 3600 秒。
- 导出检查包括采用视频、文件可访问、源范围、音频范围、输出规格与保存状态；每项错误提供对应对象和定位入口。
- 导出请求保存不可变作品快照和 `request_id`，继续编辑不影响当前导出。重复请求返回同一任务和结果。
- 创建导出快照前保存当前作品内容，记录实际返回的作品修订；输出规格只修改导出快照。导出期间继续编辑的内容独立保存。
- 每个会话保存最近一次导出的完整请求、固定作品内容、阶段、问题和结果版本。任务结果的保存不依赖编辑器保持打开；切换工作区后可以继续查看已有任务。
- 重新打开编辑器后，已提交的未完成记录查询服务端状态；正在编码时持续查询，完成后保存固定成片版本。仍有原提交请求执行时等待其结果。未知结果保留「导出结果待确认」，用户通过「恢复导出」提交原请求；查询失败保留记录并显示错误。旧请求的响应不修改新记录，已经确认的完成版本保持固定。查询本身不提交导出请求。
- 已提交请求的输出字段保持只读；「使用当前作品」创建新的独立快照。导出进行中禁止重复提交或替换记录。
- 百分比仅使用服务端实际进度；服务端没有百分比时显示阶段。成片登记为资产并关联作品修订，提供播放与保存文件。
- 保存成片使用当前预览的固定资产版本；项目资产归档或采用其它版本后，原成片仍可保存。文件复制在后台执行，写入并同步临时文件后替换所选目标；取消系统保存窗口时保持现有文件和作品内容。
- 编码结果通过文件登记为资产，媒体信息和封面直接从文件读取，摘要与内容复制使用固定大小的缓冲区；写入的内容通过摘要校验后登记版本。登记失败时保留作品，未经验证的文件不作为成片返回。

### 3.6 逆向与异常流程（Edge Cases）

| 编号 | 场景 | 系统处理机制 | 用户后续操作 |
|---|---|---|---|
| E01 | 文件格式不支持、损坏或解码失败 | 终止该文件导入，保留其他成功项和具体失败原因；不登记为可用媒体 | 替换文件或重试该项 |
| E02 | 重复导入或重复拖入参考 | 内容摘要与引用用途分别去重，返回已有版本或已有引用，不增加重复片段 | 查看已有资产或修改用途 |
| E03 | 第三方生成 API 超时，提交结果未知 | 保留原请求 ID，查询远端状态；禁止自动再次创建任务 | 查询状态、停止等待；确认原任务终止后重新生成 |
| E04 | Skill 未安装、被停用或不在会话权限范围 | 提交前校验并阻止运行，保留想法和目标 | 选择可用 Skill 或安装后重试 |
| E05 | Chat 忙碌、等待审批或等待补充信息 | 请求进入现有队列；显示状态与定位消息入口，保存原输入草稿 | 调整队列、回答问题、按现有权限流程审批或取消 |
| E06 | 生成期间切换分镜或删除目标 | 请求按提交目标处理；删除目标后保留结果记录，终止自动写回 | 从任务结果手动采用到其他分镜 |
| E07 | Chat 与手动编辑修改同一字段 | 保存两份内容与基线，打开 F13；冲突解决前保留当前作品 | 选择内容或手动合并 |
| E08 | 保存失败后切换会话或关闭窗口 | 保留草稿，阻止无提示离开，打开 F15；异常退出后可恢复 | 重试保存、留在编辑器或明确放弃 |
| E09 | 源素材较短、裁剪越界或无效数值 | 提交前就地校验；越界操作不提交，时长影响通过 F12 展示 | 调整范围、缩短分镜或替换素材 |
| E10 | 参考类型与工作流字段不匹配 | 引用资料继续保留，阻止缺少有效输入的生成，定位字段 | 选择其他字段、用途或工作流 |
| E11 | 采用新视频后首尾帧引用对应旧版本 | 标记关联引用需要核对，展示来源和版本 | 更新引用或明确保留原版本 |
| E12 | 生成失败、被取消或返回无效素材 | 保留当前采用视频和已有候选；任务显示真实状态与原因 | 检查参数并重新生成 |
| E13 | 导出期间编辑作品、重复提交导出 | 使用提交快照与稳定请求 ID；当前编辑独立保存 | 等待已有任务或按新修订发起新导出 |
| E14 | 导出素材失效、写入文件失败或编码失败 | 任务失败，保留作品与可用资产；未结束文件不登记为成片 | 定位素材、选择可写位置或重试 |
| E15 | 导入或读取资产期间改变选择、工作流或输入参数 | 使用操作开始时绑定的目标；上传参数提交前检查工作流版本及原值，变化时保留已导入资产与当前参数 | 从项目资产重新选择素材与目标 |
| E16 | 输入文字时按下播放、删除或撤销快捷键 | 编辑器全局快捷键忽略输入区域，保留原生文字编辑行为 | 正常输入，退出输入后使用编辑快捷键 |

## 4. 核心数据字段（Data Schema）

- 下列字段描述目标数据结构；保留现有字段名称，新增字段在备注中标记。
- Entity 表示业务对象。作品、分镜和引用继续保存在作品快照；请求、任务和资产复用已有存储，不要求为每个 Entity 新建数据库表。
- 必填字段允许空数组或空字符串时在备注中注明。旧文档由显式版本迁移补充新增字段；无法识别的文档格式直接返回错误。
- 素材位置由 `assetId` 与 `versionId` 解析；`url` 为运行时访问地址，不作为跨设备持久标识。

## 5. 上线验收标准（Definition of Done — DoD）

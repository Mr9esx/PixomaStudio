# 资产库项目文件夹与预览交互

使用 `executing-plans` 在当前工作区顺序处理，沿用现有 Rust API、React Query 和 shadcn 组件。

## 页面结构

资产库首页展示项目文件夹，包含未归属入口。进入项目后显示面包屑、筛选工具和资产网格。项目文件树保留分组方式、键盘导航及宽度调整，当前资产与祖先分组同步显示。

卡片默认通过整张卡片打开预览。工具栏的「选择」开启多选，勾选控件放在名称区域。更多操作放在名称同行，悬停和键盘聚焦时显示；右键菜单提供同样的下载与文档操作。

详情沿用页面内大预览，属性使用统一的 16px 内距和 20px 分组间距，页首显示项目与文件名称，文件操作收进更多菜单。

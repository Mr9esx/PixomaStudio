# 视频编辑器空间与时间轴交互计划

执行方式：主会话使用 executing-plans 顺序执行，当前 demo 目录内编辑。

目标：使用完整宽度预览视频，常用操作在时间轴直接执行，详细属性按需展开。

使用 React、已有 shadcn/ui 与 Remotion，不新增依赖。

- 桌面工作区导航高度不超过 48px，默认无常驻分镜属性。

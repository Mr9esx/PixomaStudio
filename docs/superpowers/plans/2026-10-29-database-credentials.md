# 应用数据库凭据存储实施计划

目标：登录凭据、模型 API Key 和 MCP 凭据均保存在当前应用数据目录的 `studio.sqlite`。

设计：模型记录直接保存 `api_key`，MCP 连接记录直接保存 `credential`，`platform_sessions` 按平台地址保存 Cookie。运行记录和官方专家会话保存创建时的完整模型配置，页面响应隐藏凭据内容。

使用的技术：Rust、SQLx、SQLite、Tokio。

约束：保持现有用户修改；所有检查使用真实 SQLite；测试目录位于 `.local-cache/`；数据库错误直接返回；设置直接保存在对应的应用数据库记录中。

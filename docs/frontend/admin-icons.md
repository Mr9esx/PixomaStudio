# Studio 图标清单

导航和页面标题使用相同的业务图标，图标来源为 `lucide-react`。

| 对象 | 图标 |
| --- | --- |
| 对话 | `MessageCircle` |
| 资产库 | `Library` |
| 工作流 | `Workflow` |
| 技能与专家入口及页面标题 | `Sparkles` |
| 技能标签、引用和空状态 | `Sparkles` |
| 专家标签、引用和空状态 | `Bot` |
| 设置 | `Settings2` |
| 项目文件夹与分类 | `Folder`，展开后使用 `FolderOpen` |
| 资产选择模式 | `SquareCheck` |
| 资产更多操作 | `Ellipsis` |
| 视频作品入口与作品列表 | `Video` |
| 视频编辑器逐帧播放 | `StepBack`、`StepForward` |
| 视频编辑器分镜定位 | `SkipBack`、`SkipForward` |
| 视频编辑器监听音量 | `Volume2`、`VolumeX` |
| 视频编辑器快捷键 | `Keyboard` |
| 视频编辑器适应全部时间轴 | `Scan` |
| 视频编辑器时间轴吸附 | `Magnet` |
| 视频编辑器轨道显示设置 | `MoreHorizontal` |
| 视频编辑器全屏预览 | `Maximize` |
| 视频编辑器恢复布局 | `RotateCcw` |
| 视频编辑器剧本请求与对话定位 | `MessageCircle` |
| 视频编辑器作品设置 | `Settings2` |
| 视频编辑器导出与保存成片 | `Download` |
| 视频编辑器资产视图 | `LayoutGrid`、`List` |
| 视频编辑器资产操作 | `MoreHorizontal` |
| 返回与文件位置 | `ArrowLeft`、`ChevronRight` |

品牌标识继续使用现有 `AppTitle`，图标按钮保留可访问名称。

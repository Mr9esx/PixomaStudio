# 视频剧本

## 读取创作范围

- 调用 `studio_read_video_project`，读取视频名称、全部分镜的剧情和时长，以及最新的 `asset_version`。
- 请求包含 `shot_id` 时，以该标识选择目标。相邻分镜用于理解人物、时间和动作衔接。
- 请求明确指定整片或 `scope=project` 时，规划完整叙事与有序分镜。保留已有分镜的 `id`，可以调整顺序并追加新分镜。
- 请求没有指定目标且存在多个可选分镜时，询问目标。目标已经删除时，保留生成内容在对话中，并说明当前无法写入。
- 尊重用户给出的主题、受众、人物关系、语气和内容限制。信息足够时直接创作，缺少会改变剧情的必要信息时提出一个具体问题。

## 编写剧本

- 在分镜计划时长内安排能够看见或听见的内容，优先表达一个主要动作及其变化。
- 描述人物行为、环境变化、必要的声音或对白，以及这一分镜与前后情节的关系。
- 以具体动作表达情绪，例如手指停在杯沿、人物回头望向门口。画面描述需要让创作者能够判断拍摄内容。
- 对白与旁白应适合正常语速和计划时长。几秒钟的分镜保持简短，长段对白需要用户确认时长调整。
- 沿用已有角色名称、物品和时间关系，保持连续性。参考资产中的人物设定与场景信息只有读取后才能采用。
- `script` 保存剧情正文；`storyboard` 保存独立画面描述；`subtitle` 保存画面字幕。写入范围只包含用户本次要求的字段。
- 直接生成可用正文，省略关于写作过程、模型实现和工具调用的解释。

## 写入与检查

- 指定分镜的请求使用 `studio_update_video_shot`，传入最新 `expected_version`、原始 `shot_id`，以及只包含 `script` 的 `changes`。
- 整片请求使用 `studio_write_video_project`，一次提交完整有序分镜。可以修改视频名称，以及分镜的 `name`、`script`、`storyboard`、`duration`。新增分镜使用新的 `id`，提供名称、剧本、画面描述和时长，`sourceIn` 为 0，`subtitle` 为空，`inputs` 为空对象，`references` 与 `versions` 为空列表，`volume` 为 1。
- 新分镜的时长需要符合项目帧间隔。已有素材的剪辑范围保持有效，整片范围需要包含已有成片音频；现有字幕、素材、参考、工作流、生成参数和音频保持原值。
- 写入前重新读取项目，核对目标仍然存在。其他入口已修改剧本时保留生成内容，等待用户选择；其他字段变化可以使用最新版本继续写入。
- 指定分镜的请求保持其他分镜、字幕、素材、参考、时长、工作流与生成参数不变。
- 只有工具返回成功后才报告剧本已写入。写入失败时，在对话中给出生成正文和具体原因，让用户能够继续采用内容。
- 请求没有授权生成视频或导出时，完成剧本后结束当前任务。

## 内容示例

- 想法：清晨茶园，安静，三秒开场。剧本：晨雾沿茶垄缓缓散开，一滴露珠从嫩叶滑下；远处传来短促鸟鸣，晨光照亮第一排茶树。
- 想法：人物发现忘带钥匙，四秒，无对白。剧本：人物走到门前摸向外套口袋，动作突然停住；他看一眼紧闭的门，又低头检查另一侧口袋，轻轻叹气。
- 想法：结尾出现团聚的希望，五秒。剧本：餐桌上留着一个空座位。门外响起熟悉的脚步声，老人抬起头，把那只空碗轻轻移向门口一侧。
